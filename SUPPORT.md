# Support

Solar Expanse Fleet Manager uses GitHub Discussions as the front door for user feedback.

## Where To Go

- Start here: https://github.com/chainbreakart/solar-expanse-fleet-manager/discussions/65
- Questions and install help: https://github.com/chainbreakart/solar-expanse-fleet-manager/discussions/categories/q-a
- Feature ideas and rough suggestions: https://github.com/chainbreakart/solar-expanse-fleet-manager/discussions/categories/ideas
- Confirmed tracked work: https://github.com/chainbreakart/solar-expanse-fleet-manager/issues
- Roadmap project: https://github.com/users/chainbreakart/projects/1

If you are not sure whether something is a bug, start with Discussions. Maintainers may turn a discussion into an issue once the problem is focused enough to track.

## What To Include

- Fleet Manager version or release installer name.
- The dashboard or page where you saw the behavior.
- What you expected vs. what happened.
- Whether the save is modded or unusual, if relevant.
- A screenshot when it explains the row or warning more clearly than text.

Please do not post private save files publicly. If a save is needed to reproduce a problem, a maintainer can coordinate a safer way to share it.
